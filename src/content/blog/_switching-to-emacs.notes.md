Timeline
Week 0: 27 Aug, Doom lands (it was still intimidating so I dint' use right away, but I did do some reserach first like reading blog posts, watchign some youtubes etc before touchign much)

Doom Emacs from the Unstraightened flake, built into the Nix store like any other package.
The catch showed up immediately: doom sync cannot write to a store path. The fix was to keep the built profile in Nix but load a mutable config.el from the repo through a symlink, so edits take effect on reload without a switch.
Development setup expanded: LSP, formatters, the usual.

Week 1: 1 to 5 Sep, agents move in

1 Sep, v1: agents as terminals. Each agent ran in a vterm pane. Attention came from per-agent hooks that called emacsclient (Claude's settings.json, a Codex notify.sh, a pi extension). Worked, but three bespoke bridges for three tools.

2 Sep, the CLI and workspaces. emacs-agent appeared: a shell script that talks to the running Emacs over the server socket so an agent can start another agent. start --hidden for workers without a window, a tab bar showing agent state per workspace, sounds on attention, OSC 52 so kills land on the system clipboard from a TTY.

3 Sep, v2: agent-shell over ACP. The big rewrite, thirty commits in one day. Swapped the vterm bridges for xenodium's agent-shell, which speaks the Agent Client Protocol to claude-agent-acp, codex-acp, and pi-acp. Attention now comes from protocol events (turn complete, permission request) instead of hooks. Same day:

Herdr retired. The batch process became a /batch-agents command reading a per-repo brief.
Remote Control terminal: ACP cannot do Claude's phone relay, so SPC a t runs the real Claude TUI in a tracked vterm, and SPC a m moves an ACP session into it by session id. Verified end to end: launch, hooks, phone prompt, resume, kill.
The project dashboard. Despite "no dashboard" on day one, SPC p p now lands on a magit-section buffer: git state, agents, mise task terminals, recent files, org todos, pull requests. SPC p ! is a transient built from mise tasks ls --json.
Config split into lisp/pj-*.el, one file per concern, with SPC h r r reloading all of them and mise run emacs:check byte-compiling everything against the built agent-shell.
Org files as the pre-issue layer: ~/org/projects/<repo>.org with Inbox and Tasks, and emacs-agent todo add so agents file findings through Emacs.
Images into agents from a terminal: clipboard paste, region screenshot, C-v does the right thing in agent buffers only.
emacs-agent report so team leads push results up; emacs-agent answer for worker permission prompts.
A mode-line click feature shipped and was reverted the same day.
4 to 5 Sep, hardening. Prompts are delivered or refused, never silently queued. Installed CLI binaries over npx. Hidden agents stop making noise.

Week 2: 10 to 11 Sep, driving the sessions

SPC z window zoom.
Session picker, steer a running turn, prompt history search, fork a session, diff the agent's working tree, set the session mode, a status line with model and thought level.
Browse to a project that projectile does not know yet.
Annotate a region into an agent with a comment.
--worktree BRANCH for workers, with a fixed home at ~/workspace/worktrees/<repo>/<branch> after rejecting two other layouts because nested worktrees showed up twice in projectile and ripgrep.
Generated titles for agent buffers from the first prompt, via a fast model.
Week 3: 16 to 17 Sep, living in it

Reveal the path under point in Finder, Quick Look for images, because a terminal Emacs cannot draw pictures.
EDITOR=emacsclient inside vterm, after getting trapped in nvim inside vterm inside Emacs.
Dashboard pull requests detect the forge from the push remote: gh for GitHub, tea for Forgejo, the aws CLI for CodeCommit, hidden otherwise.
Agent lines show model and reasoning effort. v peeks at an agent read-only, q comes back, like magit.

One window. Ghostty runs one Emacs. Editing, terminals, agents, git, tasks, and todos are buffers. A Doom workspace per project.
 
Agents are buffers. agent-shell over ACP for Claude, Codex, and pi. SPC a l/c/p starts one in the current project, uppercase picks a project. Each buffer knows its kind, root, model, thought level, state, and title. Attention is a protocol event, surfaced as a mode-line count, a sound, and SPC a n to jump to whoever has waited longest.

Agents spawn agents. emacs-agent is a CLI any agent can call: start --hidden --model --worktree, prompt, wait, read, focus, kill, report, answer, todo, info. PJ's shape for delegated work: Fable as architect, an optional team lead, workers on cheaper models in their own worktrees. Leads kill their workers after reading the result.

Remote Control is the escape hatch. When you need the phone, the real Claude TUI runs in a tracked vterm and an ACP session can move into it by id.

The dashboard is the home screen. SPC p p opens it. Git, agents with model and effort, mise task terminals, recent files, org todos, PRs from whichever forge the repo pushes to. Single keys: t test, s server, ! any task, a or cc start an agent, v peek, m magit, p PR, o todos, g refresh.

Everything is declared. Doom's profile is built by Nix. The config is a symlink into the repo so it reloads in place. New Elisp files need a home-manager switch because the lisp/ directory is a store link. mise run emacs:check catches compile errors before a reload. Docs follow Diátaxis, and each gotcha that bit went into docs/reference/troubleshooting.md.
