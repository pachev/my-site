# Docs

Working notes for this site, laid out in the [Diataxis](https://diataxis.fr) shape. Each folder answers one kind of question.

| Folder | Answers | What lives here |
| --- | --- | --- |
| `tutorials/` | "Teach me" | Lessons for a first-time reader. Empty for now. |
| `how-to/` | "How do I..." | Step-by-step recipes for a known goal. |
| `reference/` | "What is..." | Facts: frontmatter fields, file layout, build behavior. |
| `explanation/` | "Why..." | Background and the reasoning behind decisions. |

## Keeping these current

When a change alters documented behavior (a frontmatter field, a file path, a
skill step), update the matching doc in the same commit. Write in plain words,
active voice, no em dashes.
